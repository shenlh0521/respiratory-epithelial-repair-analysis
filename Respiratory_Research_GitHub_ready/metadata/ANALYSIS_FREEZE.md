# Analysis freeze

This package is a technical reassembly of frozen public-database results. No scientific result was selected or changed during submission assembly. The only presentation-level update is the prespecified equal-cell pseudotime display for Figure 6; the statistical estimate, pseudotime, lineage assignment, and cell set are unchanged.

Main evidence: PML subtype/severity/persistence, donor-aware normal ALI Slingshot trajectory, and the frozen normal-ALI maturation projection. Deconvolution is supplementary single-method sensitivity. GSE300258 is supplementary and confounded. Null, directional, non-replicated, and failed-method results are retained in supplementary/QC tables.
